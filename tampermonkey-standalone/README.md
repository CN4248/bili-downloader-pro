# BiliDL-PRO 独立版油猴脚本（不依赖服务端）

**完全在浏览器里跑**的 B站 + YouTube 下载脚本：不需要装 BiliDL-PRO 服务端、不需要开电脑上的 exe，装进 Tampermonkey 就能用。
（脚本版本 **v1.6.2**，配套 BiliDL-PRO **2.3.0**。）

```
tampermonkey-standalone/
├── bilidl-standalone.user.js   # 脚本本体（唯一需要安装的文件）
└── README.md                   # 本文件
```

## 和推送版（tampermonkey/bilidl-pusher.user.js）的区别

| | 独立版（本目录） | 推送版 |
|---|---|---|
| 依赖 | **无**，纯浏览器 | 需要 BiliDL-PRO 服务在跑（Docker / exe / 便携包），默认 `http://127.0.0.1:2197` |
| B站 下载 | 有（视频 / 图文 / 专栏 / 空间多选） | 推给服务端下载 |
| YouTube 下载 | 有（视频 / 频道 / 播放列表） | 推给服务端下载 |
| 登录 / 设置 | **脚本内小窗自己管** | 在 WebUI 里设置 |
| 定时追更 | 无 | 有（UP / 收藏夹 / 番剧 / 稍后再看 / 合集 / 文集 / YouTube 频道） |
| 1080P 以上 | 会拆成「视频轨 + 音频轨」两个文件（浏览器没有 ffmpeg） | 服务端 ffmpeg 合流，一体化 mp4 |
| 下载落盘 | 浏览器下载目录 + 子目录 | 服务端任意目录 |

## 安装

1. 浏览器装 Tampermonkey（Chrome / Edge / Firefox 均可）。
2. 打开 Tampermonkey →「添加新脚本」→ 把 `bilidl-standalone.user.js` 全文粘贴进去 → 保存。
3. 打开 B站 / YouTube 任意页面，**右下角只会出现红色悬浮按钮**（YouTube 页是「⬇ YouTube 下载」），点它才展开面板（面板默认收起，不会自动弹出）。

## 用法

### 1. B站 登录（想下 1080P 才需要）

面板「账号」区三种方式：

- **扫码登录**：点按钮弹出 B站 官方登录窗 → 手机 App 扫码 → 登录后自动检测并关闭弹窗。
- **手动 Cookie**：把浏览器里 `SESSDATA=…; bili_jct=…; DedeUserID=…` 整段贴进去 → 点「用 Cookie 登录」。脚本只写本机 `.bilibili.com` 的 Cookie，不上传任何地方；SESSDATA 被标 HttpOnly 时写不进去，会提示改用扫码。
- **刷新状态 / 退出登录**：随时检查当前登录态。

未登录也能下，但只有 720P 及以下。

### 2. 下载设置

- **清晰度**：8K / 杜比视界 / HDR / 4K / 1080P60（默认）/ 1080P+ / 1080P / 720P60 / 720P / 480P / 360P，拿不到会自动逐级回退。
- **下载子目录**：默认 `BiliDL`，文件落在「浏览器下载目录/BiliDL/…」。
- **视频重命名规则**（默认 `<video_title>-<video_id>-<video_episode>.<ext>`）
  变量：`<video_title>`、`<video_id>`、`<video_episode>`、`<video_page_title>`、`<video_author>`、`<video_quality>`、`<video_date>`、`<ext>`。
- **图文重命名规则**（默认 `<opus_title>-<opus_id>-<opus_order>.<ext>`）
  变量：`<opus_title>`、`<opus_id>`、`<opus_order>`、`<opus_author>`、`<ext>`。
- 规则里写 `/` 会在下载目录下再建文件夹，例如 `<opus_author>/<opus_title>-<opus_order>.<ext>` → `BiliDL/作者名/标题-1.jpg`。
- 线程数（1~4）与文件间隔（毫秒）也在这一区。

### 3. YouTube（v1.4.0 起）

- 打开任意 YouTube 视频 / 频道 / 播放列表页，右下角红色按钮 →「YouTube 下载」面板。
- **「浏览器直接下载」**：单视频直接进下载队列；频道 / 播放列表会先列出（最多 30 个）让你确认，再逐个入队。
- 解析方式：优先走 YouTube innertube（ANDROID_VR → WEB），失败再回退页面 `ytInitialPlayerResponse` + 签名解密。
- 1080P 及以上是 DASH 分离流：脚本会拆成 `…-v.mp4`（视频轨）与 `…-a.m4a`（音频轨）两个文件，并提示「浏览器无法合流」——要一体化文件请改用推送版（服务端有 ffmpeg）。
- 需要登录 / 年龄限制的视频：先在浏览器里登录 YouTube 再试；被判定「确认你不是机器人」时会明确提示。
- **「推送到服务端下载」**：面板里填服务地址（默认 `http://127.0.0.1:2197`，NAS 上填 `http://NAS的IP:2197`），把当前页推给 BiliDL-PRO 下载。地址填错时脚本会自动按常见端口探测并纠正。
- **面板默认收起**：打开网页只出现右下角红色悬浮按钮，点一下才展开面板（再点收起），不会一进页面就弹出来。
- **目录不会被当前页带偏**：从视频页 / 频道页 / 搜索页勾选的视频，按各自标题落盘，不会整批塞进「当前页面命名的文件夹」；只有播放列表页才按列表名建目录。
- **批量多选**：面板里勾「多选（点封面即选中）」→ 每张视频卡片左上角出现勾选框，点封面即选中（不再跳转），也可以直接点勾选框；面板显示「已选 N 个」，配合「全选本页 / 清空 / 批量推送 / 批量下载」一次处理多个视频。频道页、播放列表、搜索结果、首页、视频页右侧推荐都支持。

### 4. UP 主空间页多选

1. 打开 `https://space.bilibili.com/<uid>/upload/opus`（图文）或 `/upload/video`（视频）。
2. 面板里勾选 **「开启多选模式（点缩略图即选中）」**（默认关闭）。
3. 页面每张卡片左上角出现勾选框；点卡片即选中（不会跳转）。
4. 底部条显示「已选 N 个（视频 a / 图文 b）」，可「全选本页 / 清空 / 发送下载」。
5. 发送后任务进入面板「队列」，实时看进度与完成 / 失败数。
6. 队列工具行有「**取消全部**」：清空排队、中止在途下载，任务直接从队列删除。

### 5. 粘贴链接下载

面板「粘贴链接下载」支持一次贴多行：`www.bilibili.com/video/BV…`、`space.bilibili.com/…`、`/opus/…`、`/read/cv…`、`t.bilibili.com/…`、`b23.tv/…`（短链用 `GM_xmlhttpRequest` 跟随跳转还原）、`youtube.com/watch?v=…`、`youtu.be/…`、`/@频道名`、`playlist?list=…`。

## 风控与礼貌

- B站 接口请求带随机延迟（默认 700ms + 0~250ms 抖动），连续请求之间排队。
- 遇到 `-352 / -412 / 429` 会自动冷却（20s / 40s / 60s 递增）后重试，不硬刷。
- 下载并发默认 2，文件之间默认 900ms 间隔。
- 只在你点「发送下载 / 下载」时才请求站点，平时不扫描、不轮询、不后台跑。

## 已知限制（浏览器沙箱决定）

1. **只能存到浏览器下载目录**：网页没有权限写任意路径，「下载子目录」是靠文件名前缀实现的（`BiliDL/作者/文件`），浏览器会自动建这些文件夹。
2. **B站 单文件 MP4**：脚本用 `playurl(type=mp4)` 拿整段 MP4，清晰度上限受此限制（未登录 720P，登录常见 1080P）；4K / HDR 需要 DASH 分轨合并，脚本不做合并。
3. **YouTube 1080P+ 拆轨**：DASH 分离流会下载成两个文件，需要自己用 ffmpeg 合并（`ffmpeg -i v.mp4 -i a.m4a -c copy out.mp4`）。
4. **短链解析**依赖 `GM_xmlhttpRequest` 权限，若浏览器拦截，直接贴展开后的完整链接即可。
5. 视频列表页在**未登录**时有时不渲染卡片（B站 自身行为），登录后正常。
